============================================
  승무원 라인팀 편성 - 사용 방법 (EXE 설치 후)
============================================

■ 실행 방법
  1. 바탕화면 또는 시작 메뉴에서 "승무원라인팀편성" 실행
  2. 검은 창(콘솔)이 뜨면 정상 실행된 것입니다. 이 창을 닫지 마세요.
  3. 브라우저가 자동으로 열리지 않으면, 브라우저에서 아래 주소 입력:
     http://localhost:8080

■ 사용 순서
  1. 엑셀 파일 업로드 (사번, 이름, 성별, BASE, Rank, 직급, FROM, 재직상태 등 컬럼 포함)
  2. 자동 편성 완료 후 팀별로 인원 확인
  3. 필요 시 카드 드래그 또는 오른쪽 클릭으로 팀 이동
  4. "엑셀 추출" 버튼으로 결과 다운로드

■ 주의사항
  - 실행 중에는 콘솔 창을 닫지 마세요. 닫으면 프로그램이 종료됩니다.
  - 다른 프로그램에서 8080 포트를 쓰고 있으면 실행이 안 될 수 있습니다.
  - Java 설치 없이 사용 가능합니다 (프로그램에 포함됨).
