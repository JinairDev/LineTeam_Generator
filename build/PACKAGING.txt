승무원 라인팀 편성 — Windows 실행 파일(.exe) 만들기
================================================

준비물
------
· Windows PC (exe는 Windows에서 빌드하는 것이 가장 수월합니다)
· Node.js 20+
· Maven 3.9+
· JDK 21+ (PATH에 java, jpackage 사용)

한 번에 빌드
-----------
저장소 루트에서:

  build\package-windows.bat

동작:
  1) frontend: npm ci → npm run build
  2) backend: React 결과물을 classpath:/static 에 넣고 Spring Boot fat JAR 생성
  3) jpackage로 app-image 생성 → build\dist-windows\LineTeamGenerator\LineTeamGenerator.exe

실행 후 브라우저에서 http://localhost:8765

JAR만 필요할 때
--------------
  cd backend
  mvn package -Pbundle-frontend -DskipTests

  java -jar target\line-team-assignment-0.0.1-SNAPSHOT.jar

설치 마법사형 단일 exe
---------------------
WiX Toolset 설치 후 build\package-windows-installer.bat
(실패하면 app-image 방식만 사용해도 됩니다.)

Mac에서 개발만 할 때
-------------------
exe는 Windows에서 빌드하세요. Mac에서는 JAR만:

  cd backend && mvn package -Pbundle-frontend -DskipTests && java -jar target/*.jar

참고
----
· 프로파일 bundle-frontend 없이 mvn package 하면 API만 있는 JAR이며, UI는 포함되지 않습니다.
· Spring Boot 3.x fat JAR의 엔트리는 org.springframework.boot.loader.launch.JarLauncher 입니다.
